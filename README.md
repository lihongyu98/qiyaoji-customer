# 七钥纪 · 原页面客户版

保留个人工作台的海克斯页面主体、世界地图、强化卡、七钥细化填空、论文图解、学习进度与复习入口。客户版独立存储账号草稿，知情同意后将后续学习保存转为管理员待审标注。

## 本地启动

安装 Node.js 22 或更高版本，在本目录运行：

```sh
npm start
```

打开 http://127.0.0.1:18806/desktop.html 。无运行依赖，无需 npm install。服务只监听本机。

## 当前完成与限制

- 原页面、1045 篇目录、七钥定义、地图/图解资源和本地启动服务已包含。
- 草稿按登录账号分隔；退出或切换账号重新载入对应存储。
- 用户开启同步后，学习保存进入 ink_entries 待审队列；未同意或暂停时不采集后续保存。
- 有失败重试与本地去重，云端仍必须配置唯一约束和行级权限。
- 本仓库不包含个人学习记录、API 密钥、生产连接参数、论文 PDF、Electron 安装包或宣传视频。
- 邮箱认证依赖原 WorkBuddy Cloud，需同域部署、配置数据库并实际验证邮件与权限；上传 GitHub 不等于上线网站。
- 现有 AI 界面保留，但客户版未实现 /api/desktop 模型后端；本地服务明确返回未接通，不提供虚假评分。
- 学习草稿目前仅在浏览器保存，已同步的标注不是完整的跨设备草稿备份。

## WorkBuddy 配置

在部署环境填写 `public/customer-config.js` 中的 endpoint 与 publishableKey。不得放入管理密钥或模型密钥。生产值不要提交 Git。默认空配置为本地预览模式。

标注表 ink_entries 需要支持 uid、owner_id、pid、title、field、value、quote、anchor、evidence、audit、client。服务端必须根据认证身份约束 owner_id，强制 audit=pending，并限制读取本人记录。管理员审核、导出应复用已有受保护的收集台与 RPC；本项目不会公开个人后台。
